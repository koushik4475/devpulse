# Contributing

1. Fork the repository and create a focused feature branch.
2. Install dependencies with npm ci (or npm install on the first setup).
3. Make changes with accessible UI states and typed API models.
4. Add or update tests for behavior and error cases.
5. Run npm run lint, npm run typecheck, npm test, and npm run build.
6. Open a pull request describing behavior, screenshots for UI changes, and verification performed.

Never commit credentials, tokens, cookies, private user data, local databases, or generated private reports. Keep V1 public-API-only and do not add client-side secrets.
